# Tribe: дашборд и стратегический разбор

Статический сайт для GitHub Pages с двумя страницами:

- `index.html` — «Состояние проекта»: этап, ключевые цифры, маркетинг и продвижение (что сделали, что не получилось, что проверить), продукт и техника, риски и уроки.
- `strategy.html` — «Разворот или закрытие»: диагноз, варианты разворота, тесты на 1–2 недели и рекомендация.

Это снимок на 20 ноября 2026 по базе знаний tribe.md.

## Публичная версия

Репозиторий публичный, поэтому здесь нет секретов, паролей, адресов служебных панелей и подробностей об инфраструктуре. Страницы закрыты от поисковиков (`<meta name="robots" content="noindex, nofollow">`), чтобы внутренние материалы не попадали в выдачу по Tribe.

## Как обновить

- Цифры, хронология и таблица рекламных планов лежат в `assets/data.js`. Поменяйте значение там, и оно обновится на странице.
- Тексты списков и разбора правятся прямо в `index.html` и `strategy.html`.
- Стили общие для обеих страниц: `assets/style.css`. Тёмная тема включается по настройке системы.

Сборка не нужна: после пуша в `main` GitHub Pages сам опубликует изменения через минуту-две.

## Локальный просмотр

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```
